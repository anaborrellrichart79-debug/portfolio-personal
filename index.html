HireFlow

Organiza tu camino al empleo ideal.

Aplicación full stack para gestionar la búsqueda de empleo: postulaciones, entrevistas, contactos y calendario en un único panel. Incluye una API REST en Node.js con Express y una base de datos MySQL con esquema relacional, datos de prueba y colección de Postman para probar los endpoints.

  • Node.js
  • Express
  • MySQL
  • JavaScript ES6
  • Postman

Modelado de la base de datos desde cero: usuarios (candidato y empresa), ofertas, entrevistas y eventos, con schema.sql y seedData.sql reproducibles.

Mini e-commerce

Una experiencia de compra completa, sin frameworks.

Tienda online que recorre el flujo real de compra: catálogo con buscador y filtro por categorías, ficha de producto, carrito persistente y proceso de checkout hasta la confirmación del pedido. La interfaz está hecha con JavaScript modular, sin frameworks; para el pago se integra la pasarela de Stripe.

  • HTML5
  • CSS3
  • JavaScript (ES Modules)
  • LocalStorage
  • Fetch API
  • Stripe

Arquitectura por capas (api, servicios, ui, utiles) que separa los datos de la interfaz, con el carrito persistido en localStorage.

Mini e-commerce API

El backend que alimenta la tienda.

API REST que sirve el catálogo de productos al Mini e-commerce. Separar el cliente del servidor me permitió trabajar rutas, controladores, CORS y el consumo de la API desde el frontend con fetch.

  • Node.js
  • Express 5
  • CORS
  • API REST

Proyecto pensado como pareja del Mini e-commerce: demuestra cómo comunico dos aplicaciones independientes mediante una API.
